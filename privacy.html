learnup-web 개인정보처리방침

시행일: 2026-11-25

1. 읽는 정보

사용자가 허용하면, learnup-web은 Google의 YouTube Data API(youtube.readonly 권한)로 허용한 계정의 유튜브 채널에 있는 영상 목록만 읽습니다. 읽는 항목은 영상 제목, 영상 링크(ID), 올린 날짜, 공개 상태, 라이브 방송 상태입니다. 영상을 올리거나 고치거나 지우지 않습니다.

2. 쓰는 곳

읽은 영상 링크를 같은 선생님의 수업 회차에 붙여, 그 수업을 듣는 학생이 학생 웹에서 볼 수 있게 하는 데만 씁니다. 광고, 분석, 판매에 쓰지 않습니다.

3. 보관

허용 정보(다시 받는 열쇠)와 영상 링크는 연구소 컴퓨터 한 대에만 저장합니다. 다른 사람이나 회사에 넘기지 않습니다.

4. 허용 취소

언제든 Google 계정의 「타사 앱 및 서비스」(myaccount.google.com/connections)에서 learnup-web의 액세스를 삭제할 수 있습니다. 삭제하면 더 이상 영상 목록을 읽지 못하고, 저장해 둔 허용 정보는 연구소 컴퓨터에서 지웁니다.

5. Google API 서비스 사용자 데이터 정책

learnup-web이 Google API에서 받은 정보를 쓰고 다른 앱으로 옮기는 일은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

Privacy Policy (English)

Effective: 2026-11-25

Data accessed. With your permission, learnup-web uses the YouTube Data API (youtube.readonly scope) to read only the video list of the authorizing account's own YouTube channel: video title, video ID/link, publish date, privacy status, and live broadcast status. It never uploads, edits, or deletes videos.

Use. The video links are used only to attach class recordings to the matching lesson on the same teacher's class website, visible to enrolled students. No advertising, analytics, or sale.

Storage and sharing. The authorization token and video links are stored only on a single computer at the lab. They are not shared with or transferred to any third party.

Revoking access. You can remove access at any time at myaccount.google.com/connections. The stored token is then deleted.

Google API Services User Data Policy. learnup-web's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact. https://github.com/learnupmathlab-code/learnup-web-info/issues
